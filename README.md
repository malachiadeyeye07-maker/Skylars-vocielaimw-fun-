# Skylar's Little Corner 💗

A small, mobile-friendly mood website made with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — visual design
- `script.js` — mood buttons and messages

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload all three files to the top level (root) of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait a minute or two. GitHub will show the website URL in the Pages section.

## Personalise it
Open `script.js` and edit the messages inside the `moods` object. Each mood has a `messages` list; add or replace text between quotation marks. Keep the `\n\n` markers to create paragraph breaks.

To add photos or voice notes later, upload the media files to the repository and add them to the relevant mood section.

This is a static site: it does not collect, store, or send any personal information.
